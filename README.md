# DoorFour

Four-bar door desk for bedroom producers and AI-music finishers.

Suno and loop DAWs hard-cut or photocopy the same four bars. Session players write a hand-off that opens the door: bass walks out, nylon rises, kit opens, trumpet calls, piano resolves, then the next section lands on 1.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, and an acoustic kit. No oscillators. Audio never leaves the tab.

## Loop

1. Set BPM, key, and four chords. Those persist and drive playback and export.
2. Hear A (the static loop) against B (the door). Loudness is matched.
3. Pick a recipe. Change it while playing. It lands on the next step.
4. Export a loop WAV (tail folded onto sample 0) and a MIDI file, one chair per track.

## Export check

Loop WAV at 92 BPM, 8 bars, 48 kHz is 1,001,739 samples. The first transient is at sample 0. Peak is limited to -1 dBFS in the file. MIDI writes tempo and 4/4 on every chair track.
